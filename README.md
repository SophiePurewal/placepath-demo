# PlacePath

PlacePath is a fictional, responsive product prototype for coordinating student industry placements across three connected perspectives: placement coordinator, employer and student.

## Run locally

```bash
corepack enable
pnpm install
pnpm dev
```

Open the local address printed in Terminal, normally `http://localhost:5173`.

## Production build

```bash
pnpm build
pnpm preview
```

This prototype uses fictional people, organisations and placement data.
